# Rank-3 class icon provenance

`FGO-py/fgoImage/class/0-3.png` (Shielder), `2-3.png` (Archer), and `4-3.png` (Rider) were derived from cropped class icons in locally saved Fate/Grand Order gameplay screenshots. Processing retained only the icon polygon, resized it to the native 77 × 55 template size, and cleared RGB where alpha is zero. The original captures, crop coordinates and identifying provenance remain in private review evidence; they are not part of the public patch.

These are game artwork derivatives used as recognition templates. The project code license does not establish a new permission grant for the underlying artwork, and this provenance notice does not assert additional redistribution authorization. Preserve this distinction when reviewing or distributing the assets. No source screenshot, portrait, player information or run metadata is included in these PNGs.
